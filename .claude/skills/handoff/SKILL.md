# Handoff — 세션 인수인계 문서 생성

세션 맥락을 구조화된 문서로 요약해 새 세션에서 끊김 없이 이어간다.

> 컨텍스트 한도 도달 전 `/handoff` 호출 → 새 세션에서 `/handoff load`

> **저장 루트**: `docs/handoffs/` (프로젝트 루트 기준)

---

## 동작 흐름

`/handoff` → **SAVE 모드**, `/handoff load` → **LOAD 모드**.

### SAVE — STEP 1: 컨텍스트 수집 (자동, 추가 질문 없음)

```bash
git status
git log --oneline -10
git diff --stat HEAD
```

세션 대화에서 자동 추출: 완료된 작업 / 내린 결정과 이유 / 블로커 / 남은 작업.

### SAVE — STEP 2: 문서 생성 후 즉시 저장

```markdown
# Handoff — BLS {YYYY-MM-DD HH:MM}

## 프로젝트
- **경로**: {현재 작업 디렉토리}
- **브랜치**: {현재 브랜치}

---

## 완료된 작업
- [x] {완료 항목 1} — {간략한 결과}
- [x] {완료 항목 2} — {간략한 결과}

---

## 핵심 결정사항
| 결정 | 이유 | 영향 |
|------|------|------|
| {결정 1} | {이유} | {영향 범위} |

---

## 현재 코드 상태

### 변경된 파일
{git diff --stat 결과 요약}

### 주의할 점
- {다음 세션에서 알아야 할 비명시적 사항}
- {테스트되지 않은 부분 / 임시 처리(TODO)}

---

## 다음 작업

### 즉시 (이 세션 이어서)
- [ ] {다음 작업 1} — 예상: {소/중/대}
- [ ] {다음 작업 2}

### 이번 주 안에
- [ ] {작업}

### 블로커
- {블로커}: {해결 방법 또는 의존성}

---

## 새 세션 시작 방법
```
/handoff load
첫 번째 할 일: {다음 작업 1}
```
```

저장 경로: `docs/handoffs/{YYYYMMDD}.md`
같은 날 파일 존재 시 `_v2`, `_v3` suffix 부여 (덮어쓰기 금지). 디렉토리 없으면 생성.

완료:
```
✅ docs/handoffs/{YYYYMMDD}.md 저장 완료

새 세션에서: /handoff load
```

---

## LOAD 모드 (`/handoff load`)

새 세션 시작 시 가장 최근 handoff 파일을 불러와 브리핑한다. **읽기 전용** — 파일을 이동·삭제하지 않는다(기록 보존).

### STEP L-1: 최신 파일 탐색

`docs/handoffs/` 에서 날짜+suffix 기준 최신 파일 선택
(`YYYYMMDD_v3` > `YYYYMMDD_v2` > `YYYYMMDD`).
인수로 파일명을 직접 지정한 경우 해당 파일 사용.
디렉토리/파일이 없으면:
```
handoff가 없습니다. 먼저 /handoff로 저장하세요.
```
출력 후 종료.

### STEP L-2: 내용 읽기 + 브리핑

```
📂 {파일명} 로드 완료

## 이어받은 컨텍스트
- 브랜치: {브랜치}
- 마지막 완료: {완료 항목 요약}
- 즉시 할 일: {다음 작업 1~3개}
- 블로커: {있으면 표시, 없으면 생략}

작업 시작합니다.
```

미완료 TODO(`- [ ]`)가 있으면 추출해 강조한다.

---

## 규칙

- 호출 즉시 실행 — 추가 질문 없이 자동 수집·저장
- 저장 전 미리보기 생략 (빠른 실행 최우선). 수정 요청 시에만 초안을 보여주고 편집
- 파일명: `{YYYYMMDD}.md` (같은 날 충돌 시 `_v2`/`_v3`)
- 저장 루트는 항상 프로젝트의 `docs/handoffs/`
- LOAD는 읽기 전용 — 파일 이동/삭제 없음
- 블로커 없으면 해당 섹션 생략
- 한글 경로 가능 — 경로는 따옴표로 감쌈

---

## 예시

**사용자**: `/handoff`
```
git 상태 수집 중...
✅ docs/handoffs/20260616.md 저장 완료
새 세션에서: /handoff load
```

**사용자**: `/handoff load`
```
📂 docs/handoffs/20260616.md 로드 완료

## 이어받은 컨텍스트
- 브랜치: feat/skill-registry-optimization
- 마지막 완료: 스킬 통합 기반 + 표준화 1차
- 즉시 할 일: 중복 command archive
- 블로커: (없음)

작업 시작합니다.
```
