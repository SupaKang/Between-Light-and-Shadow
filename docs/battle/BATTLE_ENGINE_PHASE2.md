# Phase 2 전투 엔진 구조

## 전투 상태

- `BattleStart`: 파티와 적 데이터를 복사하고 민첩으로 선공 결정
- `CommandSelect`: FIGHT/CAPTURE/RUN 및 향후 기술 슬롯 선택
- `ActionResolve`: 명중·영력·봉인·피해·상태이상 순서 처리
- `StatusTick`: 화상 피해, 빙결/마비 행동 제한, 공포 배율, 지속시간 감소
- `BattleResult`: 승리·패배·계약 성공·도주 결과 생성
- `ReturnToWorld`: 결과를 파티·도감·경험치·저장 상태에 반영

## 처리 순서

`선공 결정 → 명령 선택 → 기술 유효성 검사 → 피해/상태 적용 → 지속 효과 → 상대 행동 → 승패 판정 → 결과 반영`

## 구현 분리

- `BattleState`: 전투 중 복사된 HP/Qi/상태/턴 데이터
- `BattleRules`: 피해·명중·계약·도주 계산
- `BattleCommand`: 사용자의 선택을 데이터 ID로 표현
- `BattleResult`: 월드 시스템이 소비할 결과 객체

## 검증 항목

- 같은 입력과 같은 데이터는 같은 결과를 만든다.
- 영력이 부족하거나 봉인된 기술은 실행되지 않는다.
- 상태이상 지속시간은 행동 단계마다 한 번만 감소한다.
- 계약 성공은 적 약화도와 계약 규칙으로만 결정된다.
- 전투 결과는 필드 위치를 변경하지 않는다.
