# ARTIFACT SYSTEM (유물 시스템 명세)

## 1. 유물의 본질: 양날의 검 (Buff & Debuff Coexistence)
- 본 게임의 모든 유물은 **강력한 전술적 이점(Buff)**과 **가혹한 패널티(Debuff)**를 동시에 부여한다.
- 맹목적으로 많은 유물을 모으는 것이 유리하지 않으며, 현재 파티의 조합과 보스 패턴에 맞추어 유물을 선별해야 한다.

## 2. 인벤토리 및 즉시 파괴 기능 (Instant Destroy)
- **보유 슬롯**: 최대 8개
- **인벤토리 UI 조작**: 언제든지(필드 및 전투 중 자기 턴) 유물 인벤토리를 열어 불필요한 유물을 `[파괴]`할 수 있다.
- **파괴 효과**: 즉시 해당 유물의 Buff와 Debuff가 파티에서 영구 소멸되며, 소량의 영기(EXP) 또는 엽전으로 환원된다.
