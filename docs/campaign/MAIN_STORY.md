# MAIN STORY (메인 캠페인: 흑월회 궤멸)

## 1. 시놉시스
영의 기운이 깃든 조선 산하에서, 붉은 달을 숭배하며 요괴들의 요기를 증폭시켜 국가를 전복하려는 사교 집단 **흑월회(黑月會)**가 암약한다.
플레이어는 벽사청의 영술사가 되어 팔도의 혼란을 수습하고, 각 권역에 세워진 '사악한 월인진(月印陣)'을 파괴하며 흑월회 총수를 추적한다.

## 2. 챕터 구성
- **제1장: 도선사의 붉은 안개** (권역 1)
  - 보스: 흑월회 하수인 '괴승 묘각'과 타락한 도깨비
- **제2장: 소백산의 무쇠 괴수** (권역 2)
  - 보스: 쇠를 먹고 폭주하는 '거대 불가사리'와 흑월회 주술사
- **제3장: 남해 포구의 침묵** (권역 3)
  - 보스: 영혼을 삼키는 '수살귀 군단'과 흑월회 수로총책
- **제4장: 지리산 여우골의 미궁** (권역 4)
  - 보스: 결계를 지키는 '백발의 구미호'와 흑월회 좌호법
- **최종장: 일식의 성채 (흑월의 밤)** (권역 5)
  - 최종 보스: 흑월회 교주 '묵영(墨影)' & 혼돈의 고대 흉수
