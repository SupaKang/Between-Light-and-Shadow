# 📐 [108: 음양견문록] 전 화면 UI/UX & 그래픽 배치 정밀 마스터 플랜
## (320x180 해상도 기준 전수 화면 경우의 수 및 픽셀 좌표 설계도)

---

## 1. 해상도 및 기본 그리드 원칙

* **네이티브 해상도**: **320 x 180** (16:9 와이드, 모던 레트로 표준)
* **타일 규격**: **16 x 16** (화면에 가로 20칸 $\times$ 세로 11.25칸 노출)
* **폰트 규격**: 영문/숫자 `8x8`, 완성형 한글 `12x12` (줄간격 14px)
* **UI 테마 원칙**:
  - 배경: 닥종이/창호지 톤 (`#E0F8D0` DMG Pale or `#181C28` 흑묵)
  - 외곽선: 짙은 먹선 (`#081820` Darkest DMG / `#0A0C10`)
  - 포인트: 황금색(선택/강조), 청록/비취(체력/영력/버프), 주홍(위험/디버프)
* **윈도우 렌더링**: 9-슬라이스(9-Slice) 절차적 테두리 (모서리 $4\times 4$ + 수평/수직 테두리 + 내부 채움)

## 4. UI 렌더링 시스템 규격 (9-Slice Engine Spec)

1. **테두리 스킨 규격**:
   - `FRAME_CORNER_TL`, `FRAME_CORNER_TR`, `FRAME_CORNER_BL`, `FRAME_CORNER_BR` ($4\times 4$ px)
   - `FRAME_BORDER_TOP`, `FRAME_BORDER_BOTTOM` ($1\times 4$ 반복)
   - `FRAME_BORDER_LEFT`, `FRAME_BORDER_RIGHT` ($4\times 1$ 반복)
   - `FRAME_INNER_BG` (닥종이/창호지 단색 또는 은은한 문살 패턴)
2. **색상 테마 팔레트 인덱스**:
   - `Theme::Standard` (조선 흑묵 + 닥종이: `#081820` / `#E0F8D0`)
   - `Theme::Night` (음기 야간 + 남청: `#0A101C` / `#2C4058`)
   - `Theme::Royal` (궁궐/관상감 + 주홍/황금: `#240808` / `#F0C040`)

## 5. 단계별 실행 계획 (Action Milestones)

1. **[Milestone 1: UI 렌더러 프레임워크 구축]**:
   - `Renderer::draw9SliceBox(x, y, w, h, theme)` 엔진 함수 구현
   - `Renderer::drawGaugeBar(x, y, w, h, cur, max, color1, color2)` 구현
   - `DialogueBox`의 대화창, 포트레이트, 팝업 선택지 완전 분리
2. **[Milestone 2: 전투 HUD & 메뉴 전면 교체]**:
   - `BattleScene`의 상단 적 HUD, 하단 아군 HUD, 하단 2x2 커맨드 윈도우 픽셀 재배치
   - `WorldScene`의 스타트 메뉴 우측 슬라이드 팝업창 정돈
3. **[Milestone 3: 관리 씬 3종 (Party / Codex / Artifact) 통일]**:
   - 좌측 리스트 + 우측 48x48 상세 카드 뷰의 2열 레이아웃 통일
4. **[Milestone 4: 인간 캐릭터 스프라이트 & 포트레이트 제작 바인딩]**:
   - 주인공/도사/NPC 16x24 오버월드 보행 4방향 + 48x48 흉상 바스트 샷
5. **[Milestone 5: 108종 요괴 배틀러 순차 제작 & 자동 바인딩]**:
   - 32x32 / 48x48 / 56x56 규격별 도트 생성 및 `asset_compiler.py` 연동
