# UI SPEC (320x180 픽셀 UI 명세)

## 1. 해상도 및 그리드 레이아웃
- **기준 해상도**: 320 x 180 (16:9)
- **타일 단위**: 16 x 16 (가로 20타일 x 세로 11.25타일)
- **안전 여백 (Margin)**: 상하좌우 4픽셀

## 2. 화면별 UI 구성

