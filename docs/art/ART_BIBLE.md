# 아트 바이블: 괴담 톤 (2026-09-24 확정 방향)

## 1. 톤

- 조선 민속 괴담이다. 달 없는 밤, 초록 도깨비불, 붉은 안개를 기본 정서로 삼는다.
- 색은 **검정과 녹색 계열이 중심**이다. 강조색은 마른 핏빛 하나뿐이다. 피부는 창백한 누런빛으로 칠한다.
- 도트는 윤곽선이 뚜렷하고 안티앨리어싱과 그라디언트를 쓰지 않는다. 얼굴과 형태는 먹선으로 분명히 읽혀야 한다.

## 2. 팔레트 (`src/art.h` 의 `GHOST[16]`)

| 번호 | 색 | 용도 |
|---|---|---|
| 0 | `#040605` | 먹, 윤곽선 |
| 1–4 | `#0a120c` `#12201a` `#1c3426` `#2a4c34` | 어둠, 그림자, 밤풀 |
| 5–7 | `#3e6e44` `#62a05a` `#a8e08a` | 이끼, 병든 초록, 인광·도깨비불 |
| 8 | `#d8e8c8` | 뼈색 흰옷, 글자 |
| 9–a | `#9aa890` `#5e6a5a` | 잿빛 |
| b–c | `#3a1216` `#7a1c1c` | 마른 피 (드물게) |
| d–e | `#c0b494` `#86785e` | 창백한 피부 |
| f | `#22262c` | 갓·검은 천 |

UI 색은 `gfx.h` 의 `UI_*` 상수로 정의한다. 배경은 거의 검정, 테두리는 녹색 이중선, 글자는 뼈색, 강조는 인광 초록, 위험 표시는 핏빛이다.

## 3. 규격

| 종류 | 크기 | 비고 |
|---|---|---|
| 필드 캐릭터 | 32x48 프레임, 4방향 × 3프레임 시트 | 2등신, 머리는 약간 작게, 옷 주름까지 표현 |
| 대화 초상화 | 96x96 | 흉상, 왼쪽을 향한 3/4 각도, 윤곽선이 뚜렷해야 함 |
| 전투 정면 / 뒷모습 | 128x128 | 화면 높이의 약 36% (포켓몬 비율) |
| 요괴 미니 아이콘 | 32x32 | 파티 화면과 도감 |
| 타일셋 | 32x32 타일, 8x8 시트 | 반복 가능한 바닥, 전환 타일 포함 |
| 아이템 아이콘 | 32x32 | |

현재 게임은 월드 320x180(16px 타일)과 UI 640x360 두 레이어로 되어 있다. 필드 캐릭터(32x48)는 640x360 층에 그리고, 시간대 색 보정은 `sprite_tint`로 맞춘다. 필드 캐릭터는 AI가 그린 3방향 시트(앞·왼쪽·뒤)를 `import_sprites.py`가 인물 단위로 잘라 32x48로 줄인다. 오른쪽은 왼쪽을 좌우 반전해 쓴다. 걷기 2프레임은 서 있는 그림에서 한쪽 발을 2px 들어 만든다. 필드용은 녹색 톤 강제 매핑 대신 괴담 팔레트에서 가장 가까운 색을 써서 허리띠 빨강 같은 식별 색을 지킨다. (코드로 도형을 찍던 방식은 2026-09-24 불합격 판정으로 폐기) 타일은 32px 타일셋이 준비되는 대로 640x360으로 옮긴다(TODO).

## 4. 제작 파이프라인

```
data/art/art_subjects.json    NPC · 타일셋 · 아이템 · UI · 컨셉 소재 (사람이 편집)
data/art/yokai_visuals.json   요괴 108종 외형 묘사 (사람이 편집)
data/yokai_*.json             게임 데이터 (이름, 등급, 속성, 출처)
        │  python3 tools/make_art_prompts.py
        ▼
assets/prompts/manifest.json  프롬프트 423개 (id, 저장 경로, 프롬프트, 변환 규격)
docs/art/PROMPT_LIBRARY.md    사람이 읽는 버전
        │  python3 tools/gen_image.py batch assets/prompts/manifest.json npc/ yokai/yokai_001 [--provider horde|gemini]
        ▼
assets/gen/<분류>/<대상>_<종류>.png  생성 원본 (마젠타 또는 단색 배경)
        │  python3 tools/import_sprites.py
        ▼
src/art_gen.h                 괴담 팔레트 16색 스프라이트 (C++ 헤더). 이름은 <분류>_<대상>_<종류>
```

- **공급자 (기본: 무료 AI Horde).** AI Horde는 커뮤니티 GPU라 비용이 없다. 익명 키로도 동작하며, `https://aihorde.net/register` 에서 무료 키를 받아 `AI_HORDE_KEY` 에 넣으면 대기 순위가 오른다. 도트 전용 모델 "AIO Pixel Art"를 쓰며, 워커가 적어 한 장에 수 분에서 10분 이상 걸릴 수 있다. Stable Diffusion 계열 모델은 프롬프트 앞부분만 반영하므로 manifest의 `prompt_short` 를 보낸다.
- Gemini(`--provider gemini`)는 품질이 높지만 쿼터 제한이 있다. 2026-09-24 기준 소진 상태다.
- Pollinations는 2026-09 기준 익명 요청이 막혀 있다. 새 엔드포인트는 API 키가 필요하고 구 엔드포인트는 서버 한도에 걸린다.
- `gen_image.py batch`는 이미 만든 파일을 건너뛴다. 중단된 뒤 다시 실행하면 이어서 진행한다.
- 변환기는 배경을 두 가지 방식으로 지운다. 마젠타가 있으면 마젠타 키를 쓰고, 없으면 모서리 색을 기준으로 바깥에서부터 채워 지운다.
- 변환기는 윤곽선을 추출한 뒤 괴담 팔레트로 매핑한다. 붉은색과 피부색은 그대로 두고, 나머지는 밝기에 따라 녹색 단계에 매핑한다.
- 필드 시트(`field_sheet`)와 타일셋은 프레임과 타일 단위로 잘라야 하므로 아직 자동 변환하지 않는다(TODO: 시트 분할기).

## 5. 인물 규칙

- **연령:** `art_subjects.json`의 NPC마다 `age`를 둔다. 프롬프트 생성기가 나이대별 외형 단서를 붙인다(45세 이상은 주름·흰머리·"치비라도 아이 같지 않은 성인 얼굴"). 2등신 비율 때문에 어른이 아이처럼 보이는 것을 막기 위한 규칙이다.
- **주인공 소품:** 낮에는 지팡이만 든다. 밤에는 지팡이와 초록 도깨비불 등불을 함께 든다(`hero` / `hero_night` 필드 스프라이트). 밤의 야외에서는 주인공 주변에 등불 빛 웅덩이(반경 22px, 디더링 경계 34px)가 생기고, 그 안의 캐릭터는 밤 색 보정을 받지 않는다.
- **필드 스프라이트 생성:** 방향마다 한 장씩 생성한다(`field_down` / `field_side` / `field_up`). 한 장에 여러 방향을 그리게 하면 모델이 순서를 지키지 않는다. 옆모습은 변환기가 얼굴 위치로 방향을 판별해 오른쪽을 보게 맞춘다. 빠진 방향은 `FALLBACK_SUBJECT`(밤 주인공 → 낮 주인공)나 앞모습으로 채운다.
- **임시 보관:** 원본 PNG가 없는 옛 스프라이트는 `src/art_legacy.h`에 둔다. 같은 이름이 새로 생성되면 변환기가 자동으로 지운다.

## 6. 검수 기준

- 1080p 실제 크기로 봤을 때 얼굴(눈·코·입)과 실루엣이 읽혀야 한다.
- 한 화면 안에서 녹색과 검정이 주를 이뤄야 한다. 붉은색은 강조가 필요한 곳에만 쓴다.
- 전승 근거가 불확실한 요괴는 `yokai_visuals.json` 에 `VERIFY` 로 표시되어 있다. 해당 디자인은 확정 전 검토를 거친다.
