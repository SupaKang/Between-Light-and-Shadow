# Full HD 조선 민속 판타지 픽셀 아트 제작 프롬프트

## 공통 스타일 프리픽스

아래 프롬프트 앞에 공통 프리픽스를 붙인다.

```text
고밀도 수작업 픽셀 아트, 조선시대 민속 판타지, 탑다운 3/4 게임 화면, 선명한 픽셀 계단과 하드 에지, 저채도 먹색·청록·황토·미색을 기본으로 한 제한 팔레트, 명암 4~6단, 작은 픽셀 군집으로 표현한 재질감, 깊은 나무 그림자, 섬세한 돌·기와·초가·나무결 디테일, 게임에 바로 사용할 수 있는 명확한 실루엣, 일관된 광원 방향, 깨끗한 픽셀 경계, 고해상도 원본이지만 픽셀 단위로 제작된 결과
```

```text
포토리얼리즘, 3D 렌더, 부드러운 브러시, 안티앨리어싱, 흐릿한 외곽선, 벡터 일러스트, 현대식 건물, 현대 의상, 일본 애니메이션풍 얼굴, 기존 게임 캐릭터, 포켓몬·다마고치·젤다의 고유 캐릭터나 로고, 복제된 타일셋, 워터마크, 읽을 수 없는 가짜 문자, 과도한 네온색, 무작위 글자, 낮은 디테일의 단순 도형
```

## 1. 마을 필드 배경

```text
Use case: historical-scene
Asset type: 960x540 top-down game background
Primary request: 조선시대 산골 마을의 낮 장면, 화면 중앙에 오래된 당산나무와 작은 제단, 왼쪽에 돌담으로 둘러싸인 초가집, 오른쪽에 기와집과 나무 대문, 화면 아래에는 흙길과 낮은 울타리
Composition: 플레이어가 걸어 다닐 수 있는 열린 중앙 공간, 건물은 화면 가장자리에 배치, 중앙 랜드마크는 실루엣이 분명하고 NPC와 플레이어가 묻히지 않도록 주변을 비움
Lighting: 흐린 오후의 확산광, 나무 아래 깊은 청록 그림자, 지붕과 돌담의 한쪽 방향 명암
Style: [공통 스타일 프리픽스]
Constraints: 32x32 논리 타일로 분해 가능한 반복 구조, 3/4 탑다운, 건물과 나무에 4~6단 명암, 독자적인 조선 민속 공간
Avoid: 현대 도시 요소, 과도하게 넓은 빈 평면, 사진 질감
```

```text
Use case: ui-mockup
Asset type: 1920x1080 game screenshot mockup
Primary request: 조선 민속 판타지 RPG의 마을 탐험 화면, 중앙에 당산나무와 제단, 아래쪽에 주인공과 NPC, 하단에 큰 대화창과 NPC 초상, 화면의 재질감 있는 픽셀 배경과 선명한 UI 프레임
Layout: 게임 월드 1920x864, 하단 대화창 1920x216, 대화창 왼쪽에 192x192 초상, 오른쪽에 한국어 3~4줄 텍스트 영역, 모든 UI는 픽셀 격자에 정렬
UI: 먹색 외곽선, 미색 내부, 청록 보조색, 주홍 선택 강조, 얇은 장식 모서리, 가독성 높은 픽셀 한글 폰트

Text: 화면에 넣는 텍스트는 후처리할 예정이므로 이미지 생성 단계에서는 텍스트를 그리지 말 것
Constraints: 16:9, 카메라 중심이 명확하고 플레이어와 NPC가 배경에서 분리됨, 원본 게임의 화면 구도·로고·문구를 복제하지 않음
Avoid: 현대식 HUD, 미니맵 과다 표시, 작은 캐릭터가 배경에 묻히는 구성, 읽을 수 없는 생성 문자
```

## 제작 운용 규칙

- 생성 모델은 콘셉트와 큰 형태 탐색에 사용하고, 최종 스프라이트는 사람이 픽셀 단위로 수정한다.
- 한 번에 전체 게임을 생성하지 말고 `필드 1장 → 캐릭터 1종 → 요괴 1종 → 타일셋 → 목업` 순서로 스타일을 고정한다.
- 이미지 안의 문자는 생성하지 않고 게임 폰트 시스템에서 별도 렌더링한다.
- 생성 결과에서 특정 기존 게임 캐릭터와 유사한 얼굴·자세·소품이 발견되면 폐기하고 다시 만든다.
- 승인된 에셋에는 프롬프트, 생성일, 수정 내역, 팔레트, 최종 픽셀 크기를 함께 기록한다.
