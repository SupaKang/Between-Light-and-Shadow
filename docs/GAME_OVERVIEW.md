# 108:음양견문록 — GAME OVERVIEW

## 1. 개요 및 배경 설정
17세기 조선, 산하의 영맥(靈脈)을 관장하던 '천지음양부(天地陰陽符)'가 비밀 결사 **흑월회(黑月會)**의 주술에 의해 파괴된다.
이로 인해 조선 팔도 전역에 잠들어 있던 108종의 요괴와 신령들이 깨어나거나 요기(妖氣)에 오염되어 날뛰기 시작한다.
플레이어는 관상감 산하의 비밀 부서 '벽사청(辟邪廳)'의 신임 영술사(靈術士)가 되어, 부적과 도술을 이용해 요괴를 진정시키고 계약하며, 흑월회의 음모를 분쇄해야 한다.

## 2. 핵심 게임 특징
1. **정통 민속 설화 기반 108종 요괴 수집**: 도깨비, 구미호, 불가사리, 그슨대, 두억시니, 두두리, 어둑시니 등 생생한 한국 전승 요괴와 산해경/동양권 전승 요괴 집대성.
2. **1.44MB 초경량 레트로 엔지니어링**: 불필요한 의존성을 일절 배제하고 320x180 해상도, 16x16 타일, 순수 C++17로 빚어낸 미학.
3. **5종 전략 상태이상 턴제 전투**: 화상, 빙결, 봉인, 마비, 공포를 조합하여 강력한 상대를 제압하고 계약으로 이끄는 전술성.
4. **양날의 검 유물 시스템**: 파티를 강력하게 만들지만 치명적인 리스크를 부여하는 유물 파밍 및 전략적 파괴.
5. **민담 옴니버스 서브 퀘스트**: 한 편의 옛날이야기를 읽는 듯한 독립 단발 설화 퀘스트.
