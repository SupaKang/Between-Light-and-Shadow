## 1. 포켓몬스터 골드(GBC)의 실제 엔진 구조 분석 결과

### ① 해상도 & 타일/블록 계층 구조 (World Architecture)
- **화면 해상도**: **160 x 144** (Game Boy 표준).
- **최소 타일 단위 (Tile)**: **8 x 8 픽셀** (2-Bit Plane, 타일 1개당 16바이트).
- **블록/메타타일 단위 (Block / Metatile)**: **4 x 4 타일 = 32 x 32 픽셀** (또는 2x2 = 16x16 픽셀).
- **건물 및 지형 처리**:
  - 집 한 채를 그릴 때 무작정 큰 통짜 이미지를 쓰는 것이 아니라, **[지붕 코너, 지붕 가운데, 기둥, 창문, 문]** 등의 8x8 타일들을 조합한 **메타타일(Metatile)** 프리팹을 맵 그리드에 배치.
  - 이로 인해 연하남 마을, 금빛시티 같은 거대한 맵을 2MB 롬 안에 수십 개씩 우겨넣을 수 있었음.

### ② 캐릭터 & 스프라이트 구조 (Sprite Architecture)
- **필드 플레이어 (Overworld)**:
  - **16 x 16 픽셀** (8x8 타일 4개 조합).
  - 4방향 (하, 상, 좌, 우) $\times$ 보행 2프레임 = 단 8개의 패턴으로 모든 걷기 연출 구현.
- **배틀러 몬스터 (Battler)**:
  - **56 x 56 픽셀** (8x8 타일 7x7 조합).
  - 전면(Front) 및 후면(Back) 스프라이트 분리.
  - 전용 4색 팔레트(Color Palette)를 적용하여 160x144 화면의 상하단에 정렬.

### ③ 텍스트 박스 & 한글 폰트 시스템 (UI / Dialogue System)
- **대화창 규격**:
  - 화면 하단 5개 타일 높이 (**160 x 48 픽셀**, Y=96~144).
  - 외곽 9-슬라이스 보더 타일 + 내부 2줄 텍스트 영역.
- **한글 조합형 폰트 (12x12 / 8x8)**:
  - 영문(1바이트 8px)과 한글(2바이트 12px)이 칼같이 정렬되어 1줄에 한글 최대 12~13자 수납.
  - 텍스트가 2줄을 넘어가면 `▼` 인디케이터 깜빡임 후 `Z`키를 누르면 다음 줄로 스크롤.
- **선택지 메뉴 (Menu Window)**:
  - 대화창 내부가 아니라 **우측 상단에 독립된 9-슬라이스 팝업 윈도우**(`싸운다`, `가방`, `포켓몬`, `도망치다` 등)로 분리되어 절대 텍스트와 겹치지 않음.

### ④ 스토리 및 시네마틱 도입부 (Intro Pipeline)
1. **타이틀 화면** (칠색조/루기아 실루엣 & 프레스 스타트).
2. **오박사의 세계관 브리핑 (Prof. Oak Intro)**:
   - 화면 중앙에 오박사/포켓몬 등장 $\rightarrow$ 세계관 설명 $\rightarrow$ 플레이어 이름/성별 선택 $\rightarrow$ 축소되며 페이드인.
3. **주인공 방 2층에서 시작**:
   - 2층 방 $\rightarrow$ 계단 내려가서 어머니에게 포켓기어/시계 수령 $\rightarrow$ 연구소로 이동하는 자연스러운 동선 유도.

## 2. 지금까지 우리의 실패 원인 및 작업 방식의 획기적 전환

| 구분 | 지금까지의 엉망인 방식 (실패) | 포켓몬 골드 방식 기반의 획기적 리빌딩 (정상) |
|---|---|---|
| **타일/맵 제작** | 좌표 수식(`sin/cos`)으로 네모를 대충 칠하고 뭉뚱그림 | **8x8 / 16x16 정밀 메타타일셋 정의** $\rightarrow$ 건물/나무/돌담을 프리팹 조립식으로 맵에 1:1 칸 배치 |
| **UI 레이아웃** | 임의의 좌표에 사각형을 겹치게 그리고 크기도 불일치 | **포켓몬 골드 표준 해상도/비율 규격화** (하단 고정 48px 대화창 + 우측 상단 팝업 메뉴) |
| **폰트/텍스트** | ASCII 전용 폰트로 한글 버그 및 줄바꿈 깨짐 | **완성형 12x12 도트 폰트 완벽 내장 & 2줄 고정 자동 스크롤러** |
| **스프라이트** | 규격 없는 일러스트를 단순 리사이징하여 노이즈 발생 | **16x16 필드 캐릭터(4방향) + 56x56 배틀러 도트**로 픽셀 단위 1:1 매핑 |
| **도입부 연출** | 버튼 누르면 황량한 벌판에 즉시 스폰 | **관상감 제조관(오박사 포지션)의 컷신 오프닝 $\rightarrow$ 한옥 안방 2층 스폰** |

## 3. 즉각 실행 리빌딩 계획

1. **[포켓몬 골드 규격 메타타일셋 엔진 구축]**:
   - 초가집 프리팹 (지붕 4타일 + 벽 2타일 + 문 1타일 = 3x3 메타블록)
   - 기와집 프리팹 (용마루 3타일 + 처마 2타일 + 기둥 2타일 = 3x3 메타블록)
   - 당산나무 프리팹 (수관 4타일 + 기둥 2타일 = 2x3 메타블록)
2. **[도선사 마을(Map 0) 골드 스타일 정밀 맵핑]**:
   - 메타타일 프리팹들로 마을 가옥, 울타리 숲, 물길, 다리를 포켓몬 연두마을(New Bark Town) 수준의 완성도로 정렬 배치.
3. **[오박사식 관상감 제조관 인트로 시네마틱 탑재]**:
   - 게임 시작 시 관상감 도사와의 문답 및 108 요괴 도감 수여식 $\rightarrow$ 마을 안방에서 출발.
4. **[대화창 & 메뉴 윈도우 100% 골드 규격화]**:
   - 2줄 자동 텍스트 래퍼 + 우측 팝업 메뉴 시스템으로 어떤 대화도 밀리지 않도록 고정.
