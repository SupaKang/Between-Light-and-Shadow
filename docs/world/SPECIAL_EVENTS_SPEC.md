## 1. 다층 고저차 및 수계 시스템 (Elevation & Water Topology)

### 1.1 3단 고저차 레이어 (3-Tier Height System)
- **1단 (평지/수변, Height 0)**: 나루터 선착장, 갈대밭, 강변 모래사장, 초가마을 마당.
- **2단 (언덕/구릉, Height 1)**: 마을 본체, 주막 거리, 과수원, 낮은 돌계단으로 연결.
- **3단 (절벽/산봉우리, Height 2)**: 깎아지른 암벽, 고산 사당, 폭포 발원지, 험준한 바위 계단 및 흔들 출렁다리로 연결.
- **점프 턱(Ledge) 일방통행**: 높은 곳에서 낮은 곳으로는 턱을 뛰어넘어 지름길로 하강 가능 (단, 역주행 불가).

### 1.2 다리와 통행 기믹
- **목조 평교 / 석조 아치교**: 일반 보행 통로.
- **붕괴된 홍예교 (Broken Stone Bridge)**: 
  - 과거 요괴의 습격으로 끊어진 석교 $\rightarrow$ 나루터를 이용해야만 하는 자연스러운 레벨 디자인 당위성 제공.
  - 후반부 특정 퀘스트 완료 또는 괴력 요괴(도깨비) 계약 후 석재를 들어 올려 복구(영구 숏컷 개방).
- **절벽 출렁다리 (Suspension Rope Bridge)**: 계곡 사이를 잇는 좁은 나무 밧줄 다리 (강풍 기믹 시 흔들림).

## 2. 나루터 & 도강(渡江) 특수 이벤트 시스템

### 2.1 나룻배 사공 NPC (Ferryman System)
- **위치**: 한양 외곽 임진나루, 남해안 포구, 낙동강 어귀.
- **상호작용 플로우**:
  1. 뱃사공 NPC 대화: *"강 건너 저편은 짙은 음기가 서려 있소. 건너가시려면 뱃삯 50냥을 내시오."*
  2. 선택지: `[1. 50냥을 내고 건넌다]` / `[2. 아직 준비가 덜 되었다]`
  3. **나룻배 컷신 연출**:
     - 플레이어가 배에 탑승 $\rightarrow$ 화면이 나룻배를 따라 부드럽게 스크롤되며 강을 건너는 미니 시네마틱.
     - 뱃사공이 지역 전승이나 야생 요괴에 대한 힌트 대사를 건넴.

### 2.2 도강 중 돌발 조우 이벤트 (River Encounter Events)
- **야간 도강 시 수살귀(水煞鬼) 습격**:
  - 밤에 나룻배를 타면 일정 확률로 강 한가운데서 배가 멈추며 강물 속에서 물귀신 등장 $\rightarrow$ **나룻배 위 특수 전투 필드**로 전환!
  - 승리 시 뱃사공이 감사의 뜻으로 희귀 유물(젖지 않는 부적) 증정 및 영구 뱃삯 무료 혜택.
- **수계 요괴 파트너 특수 능력**:
  - 파티에 '물도깨비' 또는 '거북 신령'을 보유하고 있으면 뱃사공 없이도 **요괴를 타고(Surf) 강을 건너거나 강 속 숨겨진 모래톱 보물섬으로 진입 가능**.

## 3. 다채로운 환경 상호작용 & 특수 기믹 (Interactive World Gimmicks)

| 상호작용 기믹 | 위치 / 조건 | 메커니즘 및 보상 |
| :--- | :--- | :--- |
| **나루터 도강 (Ferry Crossing)** | 넓은 강 / 뱃삯 50냥 | 반대편 대륙 및 위험 지역으로의 안전한 이동 수단 |
| **소원 돌탑 쌓기 (Stone Cairn)** | 고갯길 어귀, 절벽 쉼터 | 엽전 10냥을 올리고 기도 $\rightarrow$ 파티 전원 HP/Qi 100% 회복 & 1시간 복운 버프 |
| **당산나무 오색천 묶기** | 마을 중앙 거대 고목 | 특정 부적을 바쳐 제를 지내면 해당 권역 인카운터 요괴의 계약 확률 +20% |
| **산신당 목각인형 공양** | 3단 절벽 위 산신각 | 곡차(막걸리)나 영약을 바치면 숨겨진 고대 도술 비급서 획득 |
| **절벽 줄사다리 투하** | 높은 바위 절벽 위 | 높은 곳에서 줄사다리를 아래로 떨어뜨려 영구적 상하 숏컷 개통 |
| **폭포 뒤 숨겨진 동굴** | 2단/3단 계곡 폭포 | 폭포수 뒤편으로 통과 가능한 비밀 타일 $\rightarrow$ 희귀 유물 상자 및 전설 요괴 은신처 |

## 4. 맵 렌더러 & 씬 스택 C++ 통합 구조

```cpp
namespace JoseonRPG {

enum class SpecialEventType : uint8_t {
    None,
    FerryCrossing,       // 나룻배 도강
    StoneCairnPrayer,    // 돌탑 기도 (회복/버프)
    WaterfallCave,       // 폭포 뒤 동굴 탐험
    BridgeRepair,        // 끊어진 다리 복구
    CliffRopeDrop        // 줄사다리 숏컷 개방
};

struct MapTileInteraction {
    Point triggerPos;
    SpecialEventType eventType;
    int cost;                  // 뱃삯 또는 재료
    uint16_t targetMapId;
    Point targetSpawnPos;
    std::string dialogueText;
};

} // namespace JoseonRPG
```
