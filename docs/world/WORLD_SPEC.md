# WORLD SPEC (월드 및 맵 명세)

## 1. 월드 구조 개요
조선 팔도를 모티프로 한 5대 주요 권역으로 구성되며, 각 권역은 16x16 타일 격자 기반 맵으로 구현된다.

| 권역 ID | 권역 명칭 | 주요 테마 | 등장 요괴 성향 |
| :--- | :--- | :--- | :--- |
| **REG_01** | 한양 외곽 및 도선사 고개 | 성벽, 초가마을, 당산나무, 주막 | 도깨비류, 장승귀, 삼두구미조 |
| **REG_02** | 소백산맥 험로 & 천년 사찰 | 험준한 바위산, 암자, 깊은 계곡 | 불가사리, 어둑시니, 호랑이 신령 |
| **REG_03** | 남해안 포구 & 귀신 갯벌 | 포구 마을, 안개 갯벌, 폐선박 | 수살귀, 거북 요괴, 물도깨비 |
| **REG_04** | 지리산 대나무 밀림 & 동굴 | 빽빽한 죽림, 버려진 사당, 고분 | 구미호, 천년지네, 처녀귀신 |
| **REG_05** | 음양당 본거지 (천문음양 성채)| 왜곡된 영맥, 흑백 태극 제단, 결계탑 | 오염된 신수, 음양당 고위 도사단 |

## 2. 타일맵 기술 규격
- **타일 크기**: 16x16 픽셀
- **화면 뷰포트**: 320x180 (가로 20타일 x 세로 11.25타일 표시)
- **레이어 구성**:
  1. `Background Layer`: 바닥, 잔디, 흙길, 물, 마루
  2. `Fringe/Obstacle Layer`: 벽, 나무 기둥, 가구, 바위 (충돌 플래그 포함)
  3. `Overhead Layer`: 지붕 처마, 나뭇가지 (플레이어 위로 렌더링)
- **인카운터 메커니즘**:
  - 안전 구역: 마을, 주막 내부 (인카운터율 0%)
  - 위험 구역: 풀숲, 동굴, 안개 지대 (이동 걸음 수 기반 인카운터 카운트다운)
