## 2. 목표 상태 (완료 기준)

1. 새 게임부터 제5장 최종 보스와 엔딩, 크레딧까지 **디버그 키 없이** 진행할 수 있다.
2. 요괴 108종 모두 조우, 전투, 계약, 도감 등록이 가능하다. 그림이 없으면 임시 그림으로 표시한다.
3. 장별 자동 플레이스루 테스트가 각 장의 완료 플래그까지 통과한다.
4. 맵, 이벤트, 요괴, 기술, 아이템, 조우표는 모두 데이터 파일(`data/`)과 스크립트(`data/scripts/*.lua`)에 있다. 콘텐츠를 추가할 때 C++를 고치지 않는다.
5. 저장과 불러오기(슬롯 3개)가 되고, 어느 시점에서 저장해도 이어서 진행할 수 있다.

## 4. 마일스톤

각 마일스톤은 착수 직전에 상세 구현 계획(`docs/superpowers/plans/`)을 따로 쓴다. M1은 이 문서와 함께 작성했다.

### M1. 엔진 기반 (상세 계획: `2026-09-24-m1-engine-foundation.md`)
- `game.cpp` 모듈 분리. 렌더 결과 해시가 같은지로 동작 보존을 검증한다.
- 데이터 굽기(요괴·기술·아이템·유물·상태이상), Tiled 맵 굽기, Lua 이벤트 러너.
- 저장과 불러오기, UI 위젯(스크롤 목록, 예/아니오, 수량 선택).
- **완료 기준:** 현재 플레이 흐름(프롤로그부터 장승귀까지)이 코드에 박힌 부분 없이 전부 데이터와 스크립트로 동작한다. 저장하고 불러온 뒤 이어서 진행된다.

### M2. 전투 엔진 (착수 전 전투 설계 승인 필요 ★)
- 턴 순서는 신법(SPD)+난수. 피해는 `BATTLE_SYSTEM.md` 공식에 오행 상극(×2 / 역상극 ×0.5 ★)과 치명타 5%를 곱한다.
- 상태이상 5종(`STATUS_EFFECTS.md`), 영력(요괴)과 내공(주인공).
- 명령: 기술 / 도술(공격·약화·**소환·교체·귀환**) / 도구 / 도주.
- 전투 종류: 야생, 퇴마사(트레이너형), 보스. 보스는 다단계이고 도주할 수 없다.
- 적 AI 3단계: 무작위, 상성 우선, 보스 패턴 스크립트(Lua).
- 경험치, 레벨업, 기술 습득 알림, 패배 처리(마지막 휴식처에서 기상, 엽전 20% 손실 ★).
- **완료 기준:** 전투 로직 단위 테스트 50개 이상(공식·상성·상태이상·턴 순서·소환). 장승귀전을 실제 공식으로 치른다.

### M3. 수집과 성장
- **계약:** 약화 + 계약 부적 + 요괴별 전승 조건(Lua 함수). 성공률은 `BATTLE_SYSTEM.md` 2.2 공식을 쓰고, 조건을 충족하면 +0.30. Ⅳ·Ⅴ등급은 조건 충족이 필수다 ★.
- 파티 3마리와 요괴 보관함(휴식처에서 교체 ★), 도감 108칸(만남/계약 구분).
- 레벨 1~50, 등급 승급 Ⅰ→Ⅴ(`GROWTH_SYSTEM.md`), 기술 4칸과 교체.
- **부적 제조:** 재료(한지·주사·요괴 잔재)로 부적을 만든다. 오행 부적 5종과 계약 부적.
- 상점 종류, 유물 장착(최대 8개, 버프와 디버프 동시 적용, 즉시 파괴).
- **완료 기준:** 108종 모두 데이터로 계약 가능. 계약 조건 스크립트 108개(단순 조건은 템플릿 공유).

### M4. 월드 시스템
- 조우 시스템
  - 풀숲 걸음 수 조우
  - 조사 오브젝트 조우(오브젝트 한정 요괴, 가신신앙 매핑)
  - 시간대별 출현표
- 낮/밤 세계: NPC 일과표, 밤에만 열리는 길, 밤 전용 대사.
- 휴식처 종류: 서낭당, 주막, 민가, 사찰. 휴식하면 무조건 다음 날 06:00.
- 이동 기믹: 문·계단·워프, 턱 뛰어내리기(일방통행), 나룻배, 수계 요괴 타기(★ 서핑형 이동 여부).
- 퀘스트 로그(메인·서브), 장 전환 카드, 맵 이름 표시.
- **완료 기준:** 테스트 맵에서 모든 기믹이 동작하고 자동 테스트가 통과한다.

## 6. 결정이 필요한 항목 (★ 표시, 기본안으로 진행하며 바꿀 때 알려 주면 됨)

1. 역상극 배율 ×0.5 적용 여부 (기본: 적용)
2. 계약 조건과 확률의 관계 (기본: 조건 충족 +0.30, Ⅳ·Ⅴ등급은 필수)
3. 패배 패널티 (기본: 마지막 휴식처에서 기상, 엽전 20% 손실)
4. 보관함 위치 (기본: 모든 휴식처)
5. 주인공 이름 입력 (기본: 없음)
6. 수계 요괴 타기(서핑형 이동) 도입 여부 (기본: 3장부터 도입)
7. **스토리**: 노승의 정체, 엔딩 내용(천지음양부 복원 방식), 벽사청 상관 이름. 기본안은 문서 TODO로 두고, M7 전에 사용자가 정한다
8. 장별 권장 레벨 곡선 (기본: 위 M8 표)
