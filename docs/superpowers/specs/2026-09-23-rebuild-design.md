- 작성일: 2026-09-23
- 상태: 섹션 1(슬라이스 흐름)·섹션 2(화면·입력·UI) 승인, 섹션 3(전투 공식·계약 루프) 미확정
- 이전 코드: git 태그 `legacy-v0`에 보존

## 0. 재개발 이유

이전 빌드는 콘텐츠(108종, 공식, 상태이상)를 먼저 확정하고 게임 감각을 나중에 다뤘다. 그 결과 다음 문제가 생겼다.

- 960x540 논리 해상도에 16px 캐릭터를 올려 화면이 텅 비었다.
- 타일이 무작위 노이즈로 생성되었다.
- 전투를 디버그 키(`B`)로 시작했다.
- UI 텍스트가 잘렸다.

이번 재개발은 반대 순서로 간다. 감각과 루프를 먼저 확정하고, 콘텐츠는 그 위에 올린다.

## 3. 제1장 슬라이스 흐름

1. **프롤로그.** 정체불명의 노승이 옛이야기를 들려준다. 대화 중 선택지가 두 번 나오고(이야기를 들어 본 적 있는지, 어디로 가는 길인지), 고른 답에 따라 노승의 반응이 달라진다. 옛날 한 음양사가 108 요괴와 약조를 맺어 천지음양부를 만들고 세상을 구했다는 이야기다. 노승의 정체는 TODO다. 괴승 묘각과의 관계는 열어 둔다.
2. **한양 외곽 주막, 1일째 06:00.** 주인공이 주막 방에서 일어난다. 벽사청의 명을 받고 도선사로 가는 길이다. 요괴 없이 맨몸으로 시작한다.
3. **채비.** 부적방에서 청심환과 계약 부적을 산다. 뒤주·항아리·우물을 조사한다.
4. **메인 퀘스트 1: 마을 어귀 장승귀 퇴치.** 지팡이와 도술로 싸운다.
5. **도선사 고개** (미구현). 풀숲과 오브젝트에서 조우한다. 첫 계약, 소환 전투, 밤, 산속 민가를 거친다.
6. **도선사 마을** (미구현). 음양당 하수인들과 맞선다. 묘각이 처음 모습을 드러내는 장면에서 슬라이스가 끝난다.

## 4. 시스템 규칙

- **시간.** 게임 1분 = 실제 1초. 시간대는 새벽 05–07, 낮 07–17, 저녁 17–19, 밤 19–05. 시간대마다 필드 팔레트가 바뀌고 알림이 뜬다. 전투·대화·메뉴 중에는 시간이 멈춘다.
- **휴식.** 이부자리, 서낭당, 주막, 민가 등 어떤 NPC나 오브젝트에도 휴식 이벤트를 붙일 수 있다. 휴식하면 **무조건 다음 날 06:00**이 되고, 체력과 내공이 가득 찬다. 조사 오브젝트도 다시 채워진다.
- **조사 오브젝트.** 항아리, 뒤주, 우물, 장독대, 아궁이, 뒷간, 대들보가 대상이다. 결과는 아이템, 요괴, 빈손 중 하나이며 시간대에 따라 달라진다. 오브젝트 한정 요괴는 가신신앙과 연결한다. 뒤주·곳간은 업구렁이, 아궁이는 조왕, 뒷간은 측신, 장독대는 터주, 우물은 물귀신 계열이다. (VERIFY: 전승 근거 확인 필요)
- **전투 명령 (2x2).** 기술 / 도술 / 도구 / 도주.
  - 기술: 전면 유닛의 공격. 주인공이면 지팡이, 요괴면 그 요괴의 기술 4개.
  - 도술: 주인공이 내공을 써서 부리는 술법. 공격·약화 도술과 요괴 소환·교체·귀환이 여기에 속한다.
  - 도구: 부적과 아이템.
- **내공.** 주인공 전용 자원이다. 레벨에 따라 오르고, 휴식해야만 회복된다. 요괴 기술 자원인 `영력`과는 별개다.
- **소환.** 계약한 요괴가 있으면 전투 시작 때 직접 싸울지 소환할지 고른다. 소환 뒤에는 요괴가 싸우고, 주인공은 요괴 행동 대신 도술이나 도구를 쓸 수 있다. 파티가 전멸하면 주인공이 맨몸으로 나선다. 주인공까지 쓰러지면 패배다.

## 5. 화면·입력·UI

- **두 레이어 구조.**
  - 월드: 320x180 해상도. 타일과 필드 SD 캐릭터를 그린다.
  - UI: 640x360 해상도. 창, 글자, 초상화, 전투 스프라이트를 그린다.
  - 출력: 월드를 2배로 키워 UI와 합친 뒤 3배로 확대한다(1920x1080).
  - 효과: 월드 도트는 굵게 유지하고, UI는 절반 크기 픽셀로 더 촘촘하고 정교하게 표현한다.
- **글꼴.** 본문은 Galmuri11(한글 12px 폭), 작은 라벨은 Galmuri9(10px 폭).
- **캐릭터 이미지는 용도별로 분리한다** (포켓몬 1세대 규격).
  - 필드: 16x16, 2등신, 4방향. 걷기는 1세대와 같이 보폭 프레임과 그 좌우 반전을 번갈아 쓴다. 화면에서는 4px 위로 올려 그린다.
  - 대화 초상화: 56x56 트레이너식 반신 그림을 2배로 그린다. 대화창 왼쪽 위에 붙는다.
  - 전투: 적 정면 56x56을 2배, 주인공 뒷모습 32x32를 4배로 그린다. 1세대처럼 굵은 도트가 된다.
  - 프롤로그: 노승 전신 44x72를 3배로 그린다. 1세대 오박사 등장과 같은 연출이다.
- **색 (2026-09-24 변경):** 괴담 팔레트 16색(`art::GHOST`)과 `UI_*` 색을 쓴다. 아래 4색 램프 항목은 이전 단계의 기록이다. 램프 구조는 필드 임시 그림에 그대로 쓰고, 색만 괴담 톤으로 다시 맞췄다.
- **(이전) 색: 4색 램프 (슈퍼게임보이·포켓몬 옐로 방식).** 스프라이트·타일·UI는 각자 명암 4단계 램프 하나만 쓴다. 램프는 `src/art.h`에 있다.
  - 캐릭터: 주인공은 청회색, 주모는 다홍, 노인은 회색, 노승은 황토, 장승은 나무색.
  - 배경: 풀, 흙, 돌, 밤하늘 램프.
  - UI: 한지, 중간 갈색, 단청 빨강, 먹.
  - 창은 1세대처럼 먹선 이중 테두리로 그리고, 모서리에 붉은 매듭 점을 찍는다.
- **조우 연출.** 화면이 번쩍인 뒤 좌우 교차 띠로 닫힌다. 전투 화면에서는 적이 왼쪽에서, 주인공이 오른쪽에서 미끄러져 들어온다.
- **타이틀.** 키 설명을 표시하지 않는다.
- **이미지 파이프라인.**
  - 생성: `tools/gen_image.py`로 Gemini에서 생성한다. 배경은 마젠타로 지정한다.
  - 변환: `tools/import_sprites.py`가 마젠타를 투명으로 바꾸고, 목표 크기로 줄이고, 밝기를 4단계로 나눈 뒤 캐릭터 램프를 입혀 `src/art_gen.h`에 쓴다.
  - 출처: 원본 이미지와 프롬프트는 `assets/gen/`에 남긴다.

- **이동.** 격자 이동. 한 칸에 걷기 16프레임, 달리기(B 누른 채) 8프레임. 방향키를 짧게 누르면 제자리에서 방향만 바꾼다.
- **키 배치.** A = Z/Space, B = X/Esc, 메뉴 = Enter, F11 = 전체화면. SDL GameController를 지원한다.
- **대화창.** 하단 608x60(UI 픽셀), 2줄. 글자가 한 자씩 나타나고, Z, X, Enter 중 아무 키로나 전체 표시 후 다음으로 넘긴다. 선택지에서 X는 마지막 항목을 고른다. 입력 대기 중에는 ▼가 통통 튄다. 화자 이름표, 초상화, 선택지 창을 지원한다.
- **메뉴.** 우측 세로 목록: 요괴 / 도감 / 가방 / 음양사 / 기록 / 설정 / 닫기.
- **창 양식.** 먹선 외곽, 나무 테두리, 단청 붉은 선, 한지 바탕, 놋쇠 모서리 장식.

## 6. 구현 현황 (M1 엔진 기반 완료)

- 구현됨: 타이틀(새로 시작·이어하기), 프롤로그, 장소 카드, 주막 방, 마을, 격자 이동과 충돌, 문 전환, NPC 대화, 오브젝트 조사, 부적방 상점(수량 선택), 메뉴 패널(가방 스크롤, 기록), 흐르는 시간과 팔레트, 휴식, 장승귀 전투 UI(모의 수치), 승리 시 퀘스트 완료, 패배 시 주막에서 기상, 저장 슬롯 3개.
- 코드 구조: `src/state` 공유 상태, `world` 필드, `ui` 위젯(`ListMenu`, `NumberPicker`)·대화창, `menu` 메뉴·상점, `battle`, `scenes`, `script` Lua 러너, `save` 저장, `game` 공개 API.
- 빌드 시 굽기(런타임 파서 없음, 단일 실행 파일):
  - 게임 데이터(요괴·기술·아이템·유물): `data/*.json` → `tools/bake_data.py` → `src/data_gen.h`. 아이템은 id 문자열로 다룬다.
  - 맵: Tiled `data/maps/*.tmj`(타일 종류는 타일셋 `kind` 속성, 오브젝트는 npc/warp/trigger) → `tools/bake_maps.py` → `src/maps_gen.h`. 잘못된 워프는 굽기 단계에서 실패한다.
  - 이벤트: `data/scripts/*.lua` → `tools/bake_scripts.py` → `src/scripts_gen.h`.
- 이벤트: Lua 5.4.7 정적 링크(`tools/fetch_lua.py`, SHA-256 고정). 이벤트는 한 번에 하나씩 코루틴으로 돈다. `say`/`ask`/`battle`/`warp`/`rest`/`shop`/`scene`은 멈췄다가 대화·전투·전환이 끝나면 이어간다. 스크립트 오류는 로그와 "이벤트 오류: <이름>" 알림을 남기고 조작권을 돌려준다. 이야기 상태는 정수 플래그(`quest_gate` 등)로만 둔다.
- 저장: `SDL_GetPrefPath("supakang", "YinYangChronicle")/slot<N>.sav`(N=0..2). 한 줄에 `key=value`(UTF-8, `version=1`, `map`, `x`, `y`, `dir`, `day`, `minute`, `hp`, `ng`, `level`, `money`, `playtime`(분), `item.<id>`, `flag.<이름>`). `.tmp`에 쓴 뒤 이름을 바꿔 원자적으로 교체한다. 없는 키는 기본값, 모르는 맵·벽 좌표·버전 불일치는 "손상됨"으로 표시하고 불러오지 않는다. 전투·전환·대화·이벤트 중에는 저장할 수 없다.
- 검증:
  - `CoreTest`: 시간·휴식 규칙, 한글 줄바꿈, 전체 장면 렌더, 데이터·맵·Lua 러너·위젯·저장 검사, **입력 스크립트 플레이스루**(타이틀부터 퀘스트 완료까지).
  - `RenderHashTest`: 디버그 장면 22개의 화면 해시 회귀.
  - `--shot <scene> out.bmp`로 1920x1080 스크린샷을 만든다.
- 모의 수치(TODO, 섹션 3에서 확정): 장승귀 HP 36, 지팡이 5–7, 금침술 내공 5에 12–14, 적 공격 3–5.
