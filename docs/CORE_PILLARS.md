# CORE PILLARS (4대 핵심 개발 기둥)

## Pillar 1: 전승의 진정성과 경이 (Folkloric Authenticity & Wonder)
- 단순 몬스터가 아닌 민담과 설화의 맥락을 지닌 요괴.
- 전승 70% / 해외 전승 대체 30% 원칙을 엄수하여 근거 없는 판타지 클리셰 배제.
- 대화, 도감 설명, 퀘스트에 옛 구전 설화의 맛과 어휘를 담는다.

## Pillar 2: 제약 속의 전술적 깊이 (Tactical Depth under Restraint)
- 1v1 턴제 기반에 3마리 파티 교체 전략.
- 5종 상태이상(화상, 빙결, 봉인, 마비, 공포)의 상호작용으로 강력한 적을 제압.
- 체력을 깎고 상태이상을 걸어 포획하는 '약화 후 계약'의 긴장감.

## Pillar 3: 양날의 검 유물 마스터리 (Double-Edged Artifact Mastery)
- 유물은 단순한 스탯 상승 아이템이 아님. 반드시 이점(Buff)과 대가(Debuff)가 동시에 부여됨.
- 전투 상황과 파티 조합에 따라 유물을 취사선택하고, 부담되는 유물은 인벤토리에서 즉시 파괴하는 전략적 선택.

## Pillar 4: 1.44MB 초경량 독립 실행의 미학 (Micro-Footprint Standalone Elegance)
- 320x180 해상도, 16x16 타일, 네이티브 C++17 기반의 단일 독립 실행 파일.
- 외부 엔진이나 런타임 없이도 빠르고 부드럽게 구동되는 순수 소프트웨어 렌더링/Win32 파이프라인.
