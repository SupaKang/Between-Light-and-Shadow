# Phase 1 Technical Spike

## 현재 구현

- Windows native Win32 창
- 960x540 논리 프레임버퍼
- 1920x1080 기준 2배 확대 출력 구조
- 소프트웨어 픽셀 버퍼
- ESC 종료 입력
- 32x32 타일 필드 기준 (현재 테스트 렌더러는 논리 검증용 블록 렌더링)
- 방향키 이동 입력
- 기본 지형 충돌 판정
- 확인 입력(Enter/Z) 이벤트 훅
- 대화 패널 상태 전환
- 5x7 픽셀 폰트 출력 테스트
- 데이터 배열 기반 대화 페이지 진행
- 월드 오브젝트 인접 조건 기반 상호작용
- 테스트용 전투 화면 진입/복귀(B/Enter)
- 전투 HP 바 및 3개 명령 선택
- 행동 후 적 반격과 약화도 기반 계약 판정
- 상태이상 열거형 및 화상 지속 피해
- 5종 상태이상 외부 데이터 스키마
- 빙결·마비 행동 제한 및 공포 피해 증가 처리
- 봉인된 마지막 기술의 일시 사용 제한 및 지속시간 감소
- 플레이어/적 민첩 비교에 따른 선공 판정 데이터
- 요괴·기술 외부 데이터 스키마 초안
- 외부 JSON에서 HP·민첩을 읽는 최소 런타임 로더
- 기술 JSON의 위력값을 전투 피해에 반영
- 기술 영력 비용과 부족 시 행동 제한
- 영력 저장·복원 및 저장 버전 4
- 유물 보유 상태 저장으로 저장 포맷 버전 5 적용
- 전투 승리 경험치와 레벨업 능력치 증가
- 유물 패시브 공격 보너스 및 전투 HP 대가
- 파티 메뉴에서 유물 즉시 파괴
- 소형 바이너리 저장/불러오기(S/L)
- 저장 매직·버전·체크섬 검증
- 계약 성공 결과와 파티 수 저장
- 파티 메뉴 상태 및 메뉴 진입/복귀
- 3개 파티 슬롯 ID 저장 및 계약 등록
- 3개 저장 슬롯 선택 및 저장/불러오기
- 약화도와 턴값 기반 계약 성공/실패 판정
- 필드 이동 횟수 기반 야생 조우와 전투 전환
- 지역별 외부 조우 테이블 샘플
- 조우 간격 JSON 런타임 로드
- 조우 데이터의 최소 레벨 기반 적 HP 보정
- C++17 Release 최적화 옵션
- MSVC 직접 Release 빌드 성공 (232,448 bytes)
- CMake/NMake Release 빌드 성공 (52,224 bytes)
- CMake/NMake 산출물 프로세스 기동 성공
