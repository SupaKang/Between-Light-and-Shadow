# PROJECT MASTER (SSOT: Single Source of Truth)

> **프로젝트 공식 명칭**: 108:음양견문록 (108: Yin-Yang Chronicle — 조선시대 민속 판타지 턴제 수집 RPG)  
> **문서 버전**: v1.0.0 (Frozen Specification)  
> **작성 기준일**: 2026-09-02  
> **관리 원칙**: 본 문서는 프로젝트의 모든 기획, 데이터, 코드의 단일 진실 공급원(SSOT)이며, 상호 충돌 시 본 문서의 규정이 최우선한다.

---

## 1. 프로젝트 정체성 & 핵심 목표

### 1.1 High Concept
조선시대의 산천과 마을을 무대로, 영맥의 균열로 흩어진 108종의 한국 및 동양 전승 요괴들과 조우하고 교감하며, 이들을 계약·육성하여 조선을 파멸로 이끄는 사설 음양학파 **'음양당(陰陽堂)'**에 맞서는 초소형 레트로 턴제 수집 RPG.

### 1.2 Primary Constraint: 1.44MB 독립 실행 바이너리
- **바이너리 총량 한계**: 1.44MB (1,474,560 Bytes) 이하
- **외부 런타임**: 일체 배제 (Web View, Electron, .NET/Java 가상머신, 거대 DLL 배제)
- **실행 환경**: Windows 10/11 x64/x86 네이티브 C++17 단일 실행 파일 (.exe)
- **오프라인 동작**: 서버 통신 및 네트워크 의존성 0%

## 2. 핵심 시스템 명세

### 2.1 요괴 시스템 (Yokai System)
- **총 개체 수**: 108종
- **전승 배분 원칙**:
  - 한국 전승 요괴: 70% (~76종)
  - 해외 전승 대체 요괴: 30% (~32종) (중국 산해경/일본 요괴/동남아/서역 전승 활용)
  - 근거 없는 현대식 임의 창작 요괴는 배제
- **등급 체계**: Ⅰ등급 ~ Ⅴ등급
  - 등급 상승 시 기본 능력치 성장 배율 증가 (Ⅰ: 1.0x, Ⅱ: 1.25x, Ⅲ: 1.5x, Ⅳ: 1.85x, Ⅴ: 2.3x)
- **성장 체계**:
  - 레벨: Lv.1 ~ Lv.50
  - 5대 기본 스탯:
    1. **체력 (HP)**: 생명력
    2. **영력 (Qi/Spirit)**: 기술 사용 자원
    3. **완력 (ATK)**: 물리 공격력
    4. **호신 (DEF)**: 물리/영술 방어력
    5. **신법 (SPD)**: 턴 우선권 및 회피 보정
- **기술 슬롯**: 1마리당 최대 4개 기술 장착
- **고유 특성 (Trait)**: 요괴당 1개의 고유 패시브 효과

### 2.2 5대 상태이상 시스템 (Core Status Effects)
전투 중 중첩되지 않으며, 상태이상 우선순위 규칙에 따라 1개만 활성화된다.

| 상태이상 | 명칭 | 발동 및 지속 메커니즘 | 해제/완화 조건 |
| :--- | :--- | :--- | :--- |
| **화상 (Burn)** | 옥화 (獄火) | 공격 기술(물리/영술) 사용 시 최대 HP의 12.5% 자가 피해 발생 | 3턴 경과 또는 냉기 기술 피격 |
| **빙결 (Freeze)** | 빙결 (氷結) | 1~3턴간 완전 행동 불능 (턴 스킵) | 데미지 피격 시 즉시 해제 |
| **봉인 (Seal)** | 부적 봉인 | 가장 마지막에 사용한 기술 1개를 해당 전투 종료 시까지 사용 불가 | 해당 전투 종료 시 |
| **마비 (Paralysis)** | 뇌격 마비 | 매 턴 시작 시 33% 확률로 행동 실패 (3~5턴 지속) | 3~5턴 경과 |
| **공포 (Fear)** | 귀기 공포 | 주는 피해 25% 감소 + 받는 피해 25% 증가 (3턴 지속) | 3턴 경과 또는 사기 진작 기술 |

### 2.3 턴제 전투 시스템 (Turn-Based Battle)
- **교전 형태**: 1 vs 1 직접 대결 (파티 보유: 최대 3마리)
- **교체 규칙**: 턴 시작 시 파티 내 다른 요괴로 교체 가능 (교체 행동 시 1턴 소모)
- **턴 결정식**: `SPD` 수치 + 난수(-2 ~ +2)를 비교하여 선공 결정
- **피해 공식**:
  $$\text{Damage} = \left( \frac{\text{Attacker.ATK} \times \text{Skill.Power}}{\text{Defender.DEF} \times 2} \right) \times \text{TraitMod} \times \text{ArtifactMod} \times \text{StatusMod}$$
- **약화 및 계약 (Contract / Capture)**:
  - 야생 요괴 조우 시 체력을 깎고 상태이상을 부여하여 계약 확률 상승
  - 계약 성공률 공식:
    $$\text{CaptureRate} = \left( 1.0 - \frac{\text{CurrentHP}}{\text{MaxHP}} \right) \times 0.6 + (\text{StatusEffectActive} ? 0.25 : 0.0) + \text{PlayerCharmBonus}$$

### 2.4 유물 시스템 (Artifact System)
- **수집 및 보유**: 인벤토리 슬롯(최대 8개)에 보관되며 보유 즉시 파티 전역에 패시브 효과 적용
- **양날의 검 (Buff + Debuff 상시 공존)**:
  - *예시 1*: `도깨비 감투` ➔ 아군 치명타 확률 +30% / 매 턴 시작 시 영력(Qi) 5 감소
  - *예시 2*: `천년 묵은 지네의 알` ➔ 아군 독/화상 피해 면역 / 최대 체력 -20%
  - *예시 3*: `여우구슬의 파편` ➔ 영술 공격력 +40% / 물리 방어력 -35%
- **인벤토리 즉시 파괴**: 필요하지 않거나 디버프 부담이 큰 유물은 인벤토리에서 즉시 파괴(소멸) 가능

### 2.5 캠페인 및 퀘스트 구조
- **메인 퀘스트**:
  - 영맥을 교란하여 요괴들을 요기(妖氣)로 물들이는 음양당(陰陽堂) 당주 및 사대 방주 궤멸
  - 5개 핵심 구역(한양 외곽 ➔ 소백산맥 험로 ➔ 남해안 포구 ➔ 지리산 밀림 ➔ 음양당 본거지) 순차 개방
- **서브 퀘스트 (민담/야사 기반 단발성)**:
  - 메인 스토리와 독립된 조선 야사, 전우치전, 어우야담, 삼국유사 기반 설화
  - 퀘스트 보상: 전승 요괴 계약 기회, 고유 유물, 성장 비급

## 3. 기술 아키텍처 & 렌더링 명세

### 3.1 렌더링 파이프라인
- **내부 가상 캔버스**: 320 x 180 (16:9 비율, 57,600 픽셀)
- **프레임 버퍼**: `uint32_t pixels[320 * 180]` (32-bit ARGB)
- **윈도우 출력**: Win32 `StretchDIBits` 또는 Direct2D를 이용해 창 크기에 맞추어 정수 배율(1x, 2x, 3x, 4x, 전체화면)로 업스케일
- **타일 규격**: 16x16 픽셀 (화면 가로 20타일 x 세로 11.25타일 표시)

### 3.2 1.44MB 용량 예산표 (Size Budget)

| 구성 요소 | 목표 할당 용량 | 최적화 전략 |
| :--- | :--- | :--- |
| **코어 엔진 & 게임 로직 바이너리** | ~250 KB | C++17 헤비 템플릿 절제, `/O1` or `/O2` + `/GL` + `/Gy` + `/OPT:REF` |
| **요괴/스킬/맵/퀘스트 데이터** | ~150 KB | 소형 압축 바이너리 테이블 또는 경량 바이너리 포맷 |
| **타일셋 및 스프라이트 도트 에셋** | ~600 KB | 인덱스드 16/32색 팔레트, 런렝스(RLE)/Deflate 압축 |
| **사운드 & BGM (Chiptune/Gugak)** | ~250 KB | 4-채널 신디사이저, 미디/모듈 트래커 사운드폰트 기반 재생 |
| **안전 마진 (System Headroom)** | ~194 KB | 패치 및 여유 버퍼 |
| **총계** | **1,444 KB (< 1.44MB)** | **100% 충족** |
